# Asset attribution

Every asset in this project is **original to this repository** — generated by code in this repo or drawn as vector shapes in source files. Nothing was downloaded from the web, and nothing reproduces or imitates real schools, leagues, conferences, athletes, or other games' artwork.

| Asset                                                                                                          | Location                                                                       | Origin                                                                            | Status                                           |
| -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------- | ------------------------------------------------ |
| App icon, adaptive icon, splash icon, favicon                                                                  | `assets/images/*.png`                                                          | Rendered from an SVG drawn in `scripts/generate-icons.mjs` (pennant + star badge) | Original placeholder; safe to replace            |
| Campus Rally logo                                                                                              | `src/components/BrandMark.tsx`                                                 | Inline SVG (same geometry as icons)                                               | Original placeholder                             |
| Campus emblems (fox, comet, owl, spark, pilot)                                                                 | `src/components/CampusEmblem.tsx`                                              | Inline SVG of simple geometric shapes                                             | Original placeholders for **fictional** campuses |
| Token art (6 shapes), specials, Penalty Blocks, locks, Rally Tiles, sparks                                     | `src/game/phaser/scenes/textures.ts`, `src/game/shared/tokenArt.ts`            | Drawn procedurally with Phaser Graphics at runtime                                | Original placeholders                            |
| UI icons (back, pause, settings, lock, etc.)                                                                   | `src/components/Icon.tsx`, `BoosterTray.tsx`, `ObjectiveIcon.tsx`, `Stars.tsx` | Inline SVG paths                                                                  | Original                                         |
| Sound effects (`tap`, `swap`, `invalid`, `match`, `cascade`, `special`, `booster`, `objective`, `win`, `lose`) | `assets/audio/*.wav`                                                           | Synthesized from sine/triangle waves by `scripts/generate-audio.mjs`              | Original placeholders; safe to replace           |
| Music loop                                                                                                     | `assets/audio/music-loop.wav`                                                  | Synthesized 8-second I–vi–IV–V loop by `scripts/generate-audio.mjs`               | Original placeholder                             |
| Fonts                                                                                                          | —                                                                              | Platform system fonts only (no bundled font files)                                | n/a                                              |

## Third-party code (not art)

Phaser 3 (MIT), React Native / Expo (MIT), react-native-webview (MIT), react-native-svg (MIT), Zustand (MIT), Zod (MIT), AsyncStorage (MIT). Licenses are in `node_modules/<package>/LICENSE`.

## Rules for new assets

1. Record every new file here with its origin and license before merging.
2. Only use assets you created, commissioned with a written license, or that carry a license allowing commercial use in mobile games.
3. No real collegiate, league, conference, bowl, playoff, athlete, or stadium marks or likenesses; no imitation of other match-three games' art, UI, sounds, or characters.
