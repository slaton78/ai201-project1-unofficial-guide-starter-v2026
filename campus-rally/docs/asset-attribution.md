# Asset attribution

Every asset in this project is **original to this repository**: generated by a script in this repo
or drawn as vector shapes in source files. Nothing was downloaded from the web, and nothing
reproduces or imitates real schools, leagues, conferences, athletes, or other games' artwork.

| Asset                                                                       | Location                                              | Origin                                                                            | Status                                           |
| --------------------------------------------------------------------------- | ----------------------------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------ |
| App icon, adaptive icon, splash icon, favicon                               | `assets/images/*.png`                                 | Rendered from an SVG drawn in `scripts/generate-icons.mjs` (pennant + star badge) | Original placeholder; safe to replace            |
| Campus Rally logo                                                           | `src/components/BrandMark.tsx`                        | Inline SVG (same geometry as the icons)                                           | Original placeholder                             |
| Campus emblems (fox, comet, owl, spark, pilot)                              | `src/components/CampusEmblem.tsx`                     | Inline SVG of simple geometric shapes                                             | Original placeholders for **fictional** campuses |
| Onboarding illustration                                                     | `src/features/onboarding/slides.tsx`                  | Inline SVG shapes                                                                 | Original placeholder                             |
| UI icons (back, pause, settings, lock, close, play, flame, check) and stars | `src/components/Icon.tsx`, `src/components/Stars.tsx` | Inline SVG paths                                                                  | Original                                         |
| Fonts                                                                       | —                                                     | Platform system fonts only (no bundled font files)                                | n/a                                              |
| Audio                                                                       | —                                                     | None in this phase                                                                | —                                                |

## Third-party code (not art)

React Native, Expo and Expo modules, react-native-svg, react-native-screens, react-native-safe-area-context, AsyncStorage, Zustand, Zod — all MIT licensed; license files are in `node_modules/<package>/LICENSE`.

## Rules for new assets

1. Record every new file here with its origin and license before merging.
2. Only use assets you created, commissioned with a written license, or that carry a license allowing commercial use in mobile games.
3. No real collegiate, league, conference, bowl, playoff, athlete, or stadium marks or likenesses; no imitation of other match-three games' art, UI, sounds, or characters.
